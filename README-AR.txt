مشروع سكينة - بناء APK تلقائيًا عبر GitHub Actions
===================================================

هذا المشروع يحتوي على تطبيق سكينة الحالي وتجهيزات تحويله إلى Android APK.
GitHub Actions سيبني APK تلقائيًا على سيرفر GitHub، فلا تحتاج Android Studio على جهازك.

طريقة الاستخدام:
1) حمّل ZIP وفك الضغط.
2) افتح github.com وسجّل الدخول.
3) أنشئ Repository جديدًا باسم sakina-android.
4) ارفع كل محتويات هذا المجلد إلى جذر المستودع (بما فيها مجلد .github).
   تأكد من ظهور الملف .github/workflows/build-apk.yml داخل المستودع.
5) من تبويب Actions افتح "Build Sakina APK".
6) اضغط Run workflow ثم Run workflow.
   (أول مرة قد يطلب GitHub تفعيل Actions.)
7) انتظر حتى يصبح التشغيل أخضر؛ افتح صفحة التشغيل وانزل إلى Artifacts.
8) حمّل sakina-debug-apk.zip وفك الضغط، وستجد app-debug.apk.
9) انقل APK إلى هاتف Android وافتحه. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

البناء يعمل تلقائيًا أيضًا عند كل push إلى فرع main.

ملاحظات:
- هذا Debug APK للتثبيت والاختبار الشخصي. ليس إصدارًا موقّعًا للنشر على Google Play.
- تُولّد أيقونة Android وشاشة البداية من `assets/icon.png` و`assets/splash.png` أثناء البناء.
- بيانات التطبيق محفوظة محليًا على الجهاز. خذ نسخة احتياطية من داخل التطبيق قبل حذف بياناته.
- إذا فشل أول بناء، افتح سجل Actions وانسخ رسالة الخطأ؛ يمكن إصلاح إعداد البناء بناءً عليها.
